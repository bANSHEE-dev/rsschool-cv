One of the most my favorite *Kata* it's [6kyu **N-th Fibonacci**](https://www.codewars.com/kata/522551eee9abb932420004a0). 
The solution of which looks like this:
```
function nthFibo(n) {
  let fib = [0, 1];
  for(let i = 0; i < n; i++) {
    fib.push(fib[i] + fib[i + 1]);
  }
  return fib[n - 1];
}

```
